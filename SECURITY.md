# Security Policy

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in a public issue.

Use GitHub Private Vulnerability Reporting for this repository when available. If that channel is unavailable, contact the repository owner privately before publishing technical details.

Include the affected version, reproduction conditions, expected impact and the smallest practical proof of concept. Do not include real user credentials or personal data.

## Supported versions

BluShelf is pre-release software. Security fixes are applied to the latest development/release line.

## Secrets

Never commit API keys, access tokens, passwords, signing keys, keystores, private server addresses containing credentials, or user collection data.
